Selamat Datang

Website ini berisi kumpulan latihan HTML Lanjutan: list, table, form, input, button, dan semantic HTML.

Daftar Halaman

  1. List - unordered, ordered, dan nested list
  2. Table - tabel data, penjualan, colspan dan rowspan
  3. Form - berbagai input, button, dan registrasi
  4. Semantic - portal dengan elemen semantic
  5. Kegiatan - mini project pendaftaran kegiatan
  6. Debugging - perbaikan HTML yang rusak

Informasi Umum

  • Seluruh halaman hanya menggunakan HTML.
  • Tidak ada CSS dan JavaScript.
  • Semua halaman saling terhubung melalui menu navigasi.
